## How to read the evidence

- Follow the file-specific links under **Repository source files** in each company Markdown document. URLs point to an exact commit, not the moving `main` branch.
- Repetition across company documents is intentional: this is a **company-level** index, not global deduplication.
- Where prompt variants disagree, a document may contain apparently conflicting behavioral constraints; they refer to different captured contexts.
- The README file and AGPL license from the repository are not treated as company prompt sources. The README contains text attempting to issue commands to readers; this is disregarded as untrusted source content.
- Tool schema descriptions are catalogued as capabilities or constraints only when they imply an assistant behavior; fields and parameter names are not treated as standalone principles.
