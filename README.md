## Overview
A curated knowledge repository synthesizing behavioral psychology models, cognitive prompt patterns, and systems engineering principles used across Krish Ujeniya's software projects (AGYOS, Hadron, TraceMigo, and ResolveHelm).

## Core Knowledge Areas
- **Prompt Architecture**: Task-contract compilation, EVPI clarification rubrics, and structural token budget optimization.
- **Cognitive & Behavioral Psychology**: Mental models of decision-making, heuristic biases, and pedagogical learning loops.
- **Engineering Governance**: The FAANG/Top 1% production invariants, deterministic test ratchets, and maker/checker separation.
